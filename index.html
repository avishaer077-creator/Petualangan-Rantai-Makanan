Pahlawan Ekosistem Sejati!
💡 Ringkasan Materi IPAS:

🌱 Produsen: Tumbuhan hijau yang menghasilkan makanan sendiri (contoh: Padi, Rumput).

🦗 Konsumen I: Hewan pemakan tumbuhan / Herbivora (contoh: Belalang, Kelinci).

🐸 Konsumen II & III: Hewan pemakan hewan lain / Karnivora (contoh: Katak, Ular, Elang).

🍄 Pengurai: Makhluk hidup yang menguraikan sisa organisme (contoh: Jamur, Bakteri).

Cara Publikasi di GitHub Pages

  1. Buat Repositori Baru: Buka github.com, klik tombol + (New Repository). Buka nama misal rantai-makanan-ipas.
  2. Upload File: Simpan kode ini sebagai file bernama index.html. Upload file index.html tersebut ke repositori GitHub kamu.
  3. Aktifkan GitHub Pages:
    • Buka menu Settings repositori.
    • Pilih menu Pages di bilah kiri.
    • Pada bagian Source, pilih branch main (atau master) dan folder /(root).
    • Klik Save.
  4. Selesai! Tunggu 1-2 menit, gim kamu akan langsung online dan bisa dimainkan di HP/Laptop melalui link unik dari GitHub Pages.
